# Cory Besson — Portfolio

Portfolio personnel de **Cory Besson**, présentant mon parcours professionnel, mes expériences, mes compétences et mes coordonnées.

Le site a été conçu avec **Next.js**, **React**, **Tailwind CSS** et **Motion**, puis déployé avec **Vercel**.

## 🚀 Déploiement avec Vercel

Le projet fonctionne avec **Vercel**.

Le dépôt GitHub est connecté au projet Vercel. À chaque `git push`, Vercel détecte automatiquement les changements et crée un nouveau déploiement.
